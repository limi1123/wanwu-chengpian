# 视频提示词：精准时间轴、丰富镜头与真实声音

用于视频提示词的新写、压缩和局部修改。结合用户已有稿件和本轮要求做取舍；用户只改声音时，保留已确认的画面和台词。这里的秒数、镜头数量与语速范围是制作规划参考，不是生成工具的执行保证。

## 1. 锁定内容与素材用途

先提取总时长、分段限制、平台或模型、画幅、最宽景别、人物、台词语言、必须保留的文字与剧情。参考图分别说明用于人物身份、衣服版型、印花、场景还是画风；只参考印花时，不复制参考模特或背景。不把多视图、分镜板直接当作单人视频首帧。

用户提供的详细稿件优先做整理和局部优化；需要压缩时，保留主要信息、笑点与必要展示，优先删重复解释。用户要求台词逐字保留或总时长固定时，把它当作硬约束；两者确实冲突时指出具体超时句及所需选择，不擅自删词或改变时长。

本用户的生活化服装对话视频，未另作要求时沿用此前偏好：真实手机观感、自然表演、清楚的正常语速、无新增字幕与字卡、无背景音乐，以对白及真实现场声形成节奏。其他题材根据其自身风格设计；用户明确指定音乐、字幕或长镜头时按指定执行。参考图片没有声音依据，不据此声称已分析原片音效。

## 2. 先排对白，再排画面

### 台词与表演预算

- 为每句写明说话人、逐字台词、发声起止时间、情绪和必要停顿。区分出镜人声与画外音，给固定角色保持同一音色和相近听感响度。
- 快节奏靠切镜、动作、眼神和信息推进。保留疑问、重音、呼吸、接话及笑点反应；亲切、有情感，避免赶读和广告式喊话。关键笑点说完，让观众有时间理解。
- 英语日常对话可先按约 130–170 词/分钟粗估，中文可先按约 3–4 字/秒粗估；它们只用于发现明显过载。逐句考虑音节、专有名词、数字、缩写和表演停顿，短句不机械套长段平均语速。数字按实际读法估算，不能只数书写字符。
- 情绪反应和动作可以与对白自然并行，但换说话人、读小字、转脸及伸手回位需要可执行的余量。对白已占满时，先删冗余或重排画面；允许调整时再延长总时长。固定时长与完整原词都必须保留而仍放不下时，提出具体冲突。
- 精确区分“已完成文本预算”与“已试听配音”。没有音频时，只报告估算；实际配音超时应重新排时，不靠加速音轨、截断词尾或吞词硬凑。

### 时间轴表示

- 画面时间从 `00.00` 连续排到总时长；每段标明起点、终点与时长。前一镜结束等于后一镜开始，合计精确等于目标时长。按节奏需要使用 0.1 或 0.05 秒精度，避免没有意义的逐毫秒指令。
- 画面与声音分别排时间。一句台词跨镜头时，在声音安排中只记录一次完整发声区间，并在涉及的镜头写“上一句连续播放”。切画面时保留同一条完整人声，不重新念、不截句、不因景别改变音量。
- 同一角色出镜说话时要求口型同步；切到印花或听者反应时可继续画外对白。听者用眼神和小表情接话，不替画外角色张嘴，不无故重叠抢话。
- 示例：B 在 `00.15–02.85` 说完整一句；镜头 1 为 `00.00–01.30`，镜头 2 为 `01.30–03.00`。第二镜延续同一句音频，不能再分配一遍整句。这里只示范时间关系，不替实际台词保证时长。
- 分段生成时，同时列出全片时间与段内时间，每段局部从零开始；明确人物、服装、光线、声线、站位、手势状态与环境声的衔接。第二段沿用已发生的剧情，不重新发现商品或重念开场。首尾帧仅在工具支持时作为辅助参考，不保证连续性。

## 3. 丰富镜头，每次切换都提供信息

先让前 3 秒出现可理解的钩子：一句短问、一个具体细节或一个自然反应。商品、人物反应或冲突应尽早可见；长片头和空镜不能挤掉这段内容。钩子与实际产品和剧情相符。

按用途交替选择建立关系的中景、说话人近景、商品完整展示、真实细节特写和听者反应。相似构图的重复切换只有在提供新信息时才保留。一次镜头安排一个主要可执行动作，必要时增加前后小反应；景别变化不必同时叠加推拉、环绕、走位和换焦。

镜头数服从内容与用户限制：15 秒生活对话可先尝试约 6–9 镜，24 秒可先尝试约 8–12 镜，再按可读性增减。这些是起排示例，不能作为固定配额。长台词、复杂动作或读小字需要更长停留；明确指定单镜、固定机位或不切镜时，用表演节拍和细节变化丰富内容。

一个连续镜头中的“开始／变化／结束”是表演节拍，不计作三次切镜；分镜表、摘要及可复制提示词中的镜头数一致。较短插镜用于一眼可懂的细节，重要小字则完整入镜、布料停稳，并让读图与台词重合。时长随文字长度和移动端实际可读性调整。

人物动作少而自然：抬眼、轻微侧转、理平袖口、轻指图案、憋笑或一次邀请手势。手指与衣褶接触合理，展示印花时手不遮字，衣服回落符合重力；头肩比例和肩颈衔接自然。半身要求贯穿每个镜头，不能为了增加镜头数突然出现全身。相邻镜头保持人物身份、服装、印花、左右关系、光线与动作方向一致。

## 4. 声音丰富，来源清楚

声音按剧情需要分层，不要求每一镜同时出现全部层：

| 声音层 | 安排方式 |
| --- | --- |
| 对白 | 最清楚、最靠前；标固定角色、音色、语调、发声区间和自然停顿。切近景仍保持相近响度。 |
| 环境底声 | 室内空气声或实际场景的远处生活声，低而连续；硬切画面时不突然抽空，也不每镜重启。 |
| 动作拟音 | 只安排有动作来源的衣料摩擦、袖口轻擦、杯底碰木桌、轻脚步等；标触发动作与大致发生时间，低于对白。画外声源也要有场景依据。 |
| 人物细声 | 呼吸、气笑或短促轻笑，与人物情绪对应，落在合适间隙；不用反复大笑掩盖台词或制造罐头笑声。 |
| 音乐与设计音 | 用户指定或题材需要时再设计，说明入出点和对白时压低的关系；生活随拍优先现场声，不自动给每次切镜加转场音。 |

每个关键声音说明“谁／什么发声、何时发生、远近与轻重、是否延续”。声音层次来自合适的时机和空间，而不是单纯增加数量。台词进行时，把非必要拟音放轻或移至句间；结尾保留自然收音，不追加台词。提示词中的响度描述是目标，成片还需试听，不能声称仅凭文字已完成混音。

## 5. 输出可以直接使用

依据用户要求交付。完整视频方案默认包含以下内容；只要求一段可复制提示词或局部修改时，把必要信息合并进去，避免重复全稿：

1. 一句话说明总时长、分段数、实际镜头数和主要节奏；沿用用户的原始创意。
2. 参考素材清单与用途。缺失素材标“待上传”，`@名称` 是素材标签，只有工具确实绑定后才能说已绑定。保留原有印花与逐字文案，产品卖点只用有依据的信息。
3. 时间表：`镜号｜全片时间（分段时加局部时间）｜景别、动作与作用｜角色、逐字台词及独立发声区间｜现场声音`。不把一句跨镜对白复制成两次发声。
4. 每个生成段各一个 `text` 代码块：明确基础设定、人物与商品锁定、分镜时间、对白与声音、连续性及必要限制。每段可单独复制，不能只写“同上”；把必需的上一段状态和参考标签复述清楚。
5. 简短列出本次真正需要的成片核查点：总时长、句尾、口型、印花、构图、声线与对白可懂度。不把文本预算说成已生成或已验证媒体。

画幅、分辨率、帧率和生成段长以用户及可用工具为准；不能为了显得专业而添加未经核实的工具参数或平台能力。字幕、音乐、负面提示词和后期步骤按需求给出。无字幕要求下，画面内原有的衣服文字仍需保留；无额外商品界面时，购买引导用指定台词和自然手势，不生成虚构按钮。

## 6. 交付前核对

- 画面区间连续，无空档或交叠；总和、各段时长、镜头数量在表格与最终代码块一致。
- 每句有唯一说话人和完整发声窗口，跨镜头音轨连续；台词与可见口型、反应、读字和手势互相可行。
- 前 3 秒有明确内容；每次切镜有作用；关键文字可读，正常语速与句尾留白没有被镜头数量挤掉。
- 声音有对应来源、时机和层级，环境声能衔接，非对白声音不盖过人声。
- 参考用途、人物、产品图案、构图边界与用户已确认的取舍一致；固定台词和固定时长有冲突时已具体说明。

若尚未生成，只说明时间为制作目标；生成后需要结合真实音视频检查。正文直接给实用提示词，不额外讲提示词框架术语。
